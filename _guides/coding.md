Yours to write. Some questions to start from:

- How do you pick something you can reimplement in a week?
- What didn't work?

## How do you pick something you can reimplement in a week?

### Choose something that is straight forward to match

In order to implement some graph experiment you must make sure it is implementable in a week.
If you do much research and trial and error you might not converge on a result in a week.
So, if you have source code of the article's repository search it for some evaluation metrics and/or scripts that you can run with only configuration change or such.

## What didn't work?

### Run time

Before you run any experiments or evaluations, make sure to check from ahead how much time it will take.
Models in LLM tend to be larger so evaluating / training them may take a lot of time without you knowing it.
Therefore, check that what you are running takes a sufficient amount of time so you'll be able to look at it in a reasonable time.
