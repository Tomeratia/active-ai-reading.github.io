## The Paper's Main Points
The paper discusses residual connections in LLMs, it builds upon and improves a line of literature that has seeked to replace the standard skip connection. The standard skip connection has a major flaw — information dilution, all previous layer representations are compressed into a single vector. Previous works like [mHC](https://arxiv.org/abs/2512.24880) and [AttnRes](https://arxiv.org/abs/2603.15031) have improved on this by suggesting an attention-like mechanism for selectively and dynamically attending to previous layer representations. Multi-Stream Attention Residuals (MSAR) wishes to extend this into a multi-head(stream) attention, the challenge presented is doing so without additional linear projections or presistent memory. The authours solve this using causal convolutions along the sequence dimension, expanding previous layer hidden states into multiple representations (streams), for which they apply depth-wise attention like in AttnRes then fuse represntations back into a single vector like in mHC.

### 🔬 Research: the missing control
[The author background](https://active-ai-reading.github.io/posts/2026/week-2-multi-stream-attention-the-authors-path/) helps us understand the paper is part of the authors' current work towards perfecting residual connections (More recent work [xHC](https://arxiv.org/abs/2607.14530)) as part of their overall research theme of improving LLM pretraining by optimizing aspects of the architecture design. [The literature review](https://active-ai-reading.github.io/posts/2026/week-2-MSAR-literature-review/) provides context that came up again and again in class as essential for understanding this paper.

This week’s critiques ([1](https://active-ai-reading.github.io/posts/2026/critique-multi-stream-attention-residuals/), [2](https://active-ai-reading.github.io/posts/2026/critique-multi-stream-attention-residuals-odedorenstein/), [3](https://active-ai-reading.github.io/posts/2026/critique-multi-stream-attention-residuals-gilk717/), [4](https://active-ai-reading.github.io/posts/2026/critique-multi-stream-attention-residuals-adam-gabet/)) while mostly positive emphsizing the impressive empirical gains and the succesfull effort to minimize the cost they come at, all boil down to the same question: is the mechanism nessecary or are the gains coming from somewhere else? [Critique 1](https://active-ai-reading.github.io/posts/2026/critique-multi-stream-attention-residuals/) praised the w/o convolution control in this context while the other critiques mentioned “Canon layers” that improve performance via a causal convolution before attention and before the MLP alone (Allen-Zhu, 2025), suggesting the authors conflated the local context bias from the convolutions with their multihead attention. [Critique 4](https://active-ai-reading.github.io/posts/2026/critique-multi-stream-attention-residuals-adam-gabet/) provides a suggestion for a control to test this theory: “AttnRes plus a single causal convolution on the sources, one head. Add Vanilla plus Canon-A/C. If these match MSAR, the contribution is token mixing.”

[The proposed follow-up](https://active-ai-reading.github.io/posts/2026/followups-multi-stream-attention-residuals/) tests an asymmetric design using multi-stream retrieval for Attention sublayers and standard residual connectionss for the subsequent MLPs. The rational lies within the depth-wise attention maps visualizations from the paper appendix which show MLPs primarily rely on the immediate preceding sublayer anyway, this approach could drastically cut memory I/O overhead without sacrificing performance.
